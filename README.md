# Beam Designer

A Tkinter desktop app for analyzing simply supported and cantilever beams. It
calculates reactions, shear, moment, deflection, and preliminary section checks;
designs can be saved as JSON or exported as CSV and PDF.

Install the PDF dependency:

```bash
python3 -m pip install -r requirements.txt
```

Start the app with Python and Tk support:

```bash
python3 app.py
```
